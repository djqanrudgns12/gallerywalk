# 3D 모듈 규격 (PLAN §13.1, ADR-013·034·051·057)

> 모든 템플릿의 조각은 이 규격을 따른다. 엔진(배치·조립)은 이 치수를 전제로 하고, `verifyOutput.mjs`가 산출물이 규격과 맞는지 확인한다.
> 원본(.blend)은 저장소에 넣지 않는다. `tools/assets/blender/build.py`가 언제든 다시 만든다.
> 외관·설비 치수는 배치 계약(`packages/core/src/domain/templates/geometry.ts`의 `exterior`·`footprints`, `config.ts`)을
> `tools/assets/pipeline/contract.mjs`가 뽑은 `contract.json`에서 읽는다 — Blender 스크립트에 계약 수치를 다시 적지 않는다.

## 1. 좌표와 단위

- 단위 m. Blender는 Z-위로 만들고 glTF(Y-위)로 내보낸다(내보내기가 변환: Blender (x, y, z) → glTF (x, z, −y)). 그래서 **Blender −Y = glTF +Z = 조각의 앞**.
- **벽 조각**: 기준점 = 벽 시작 쪽 바닥(회반죽 면 위). 벽은 Blender +X로 뻗고, 방 안쪽은 Blender −Y(glTF +Z). 회반죽 면은 y = 0.
- **천장 조각**: 기준점 = 한 모서리, +X·+Y(Blender)로 2m씩, 아랫면이 z = 4.0.
- 높이 4.0m(`WALL_HEIGHT_M`), 벽 두께는 그리지 않는다(방 밖은 보이지 않음 — 회랑 끝은 안개, PLAN §6.6). 문·정문 조각만 벽 두께 면(0.3m)을 그린다.
- 외관 조각의 기준점·방향은 §9, 설비는 §10.

## 3. UV

- **UV0 `UVMap`**: 세계 크기 타일, 1 UV = 2m(질감 한 장 = 2m). 면의 법선 축으로 투영(벽면 → (x, z), 옆면 → (y, z), 윗·아랫면 → (x, y)). 질감은 이어 붙여도 이음새가 없게 주기적으로 만든다.
  - 회전체(기둥·화분·가로등)와 나무 줄기는 원통 펼침(u = 둘레 길이, v = 높이), 잎 카드·그림자 판은 판마다 0..1.
  - 땅 높이에 놓이는 외관 조각(날개 벽·모서리 기둥)은 **실내 바닥 높이(z = 계단 높이)를 v 0**으로 투영한다 — 현관(실내 바닥 높이 기준점)의 석재 줄눈과 높이가 맞는다.
- **UV1 `Lightmap`**: 굽기 전용, 겹침 없음. 실내는 lightmap pack(섬 사이 여백 1024 기준 4px 이상), 외관은 smart project(60°) → 섬 크기 고르게 → 묶기(여백은 해상도별). 바닥·설비는 UV1 없음.

## 5. 굽기 — 실내 (ADR-013·051)

- **표준 조명틀 = 천창**: 천장 아래 z 3.86에 벽에서 1m씩 물러난 넓은 확산광(아래를 비춤) + 어두운 환경광. x 방향으로 변하지 않아 어느 벽 조각이든 같은 빛이고, 벽 0.5~3m가 거의 고르다. 천장 레일·조명 머리는 장식이다(작품 스포트는 액자의 빛 웅덩이 판, PLAN §6.3).
- **이웃과 함께 굽기**: 벽 조각은 양옆 8m를 같은 조각 사본으로(문·정문 조각은 4m 벽 사이), 바닥·천장(방 깊이 8m), 맞은편 벽. 천장·안쪽 모서리는 8×8m 방, 바깥 모서리는 ㄱ자 공간. 정문은 문 밖 1.2m에 문을 향한 빛 판(밝은 현관 대신)을 세워 벽 두께 면 바깥 쪽이 어둡지 않게 한다.
- 굽는 값 = 흰 빛·회색 재질에서 **확산 직접광 + 간접광**의 밝기(RGB 평균) → 위치·법선 굽기를 길잡이로 한 결합 양방향 걸러내기(잡음 제거) → **모든 실내 조각 공통 노출**(4m 벽 회반죽 x 0.5~3.5·z 1.3~2.3 평균이 0.62가 되게) → 곡선 `1 − e^(−x)` → 8비트 선형 PNG. 노출 값은 `manifest.json` `exposure`에.
- 굽기 회색 반사율(`BAKE_GRAY`)은 밝아진 기본색 평균에 맞춘다(회반죽 0.80, 참나무 판 0.33, 몰딩 0.22 …) — 이웃이 되튕기는 빛.
- glTF에는 `occlusionTexture`(texCoord 1)로 싣는다(glTF에 lightMap 칸이 없음). three는 불러올 때 `lightMap`(channel 1)으로 옮겨 조도에 더한다. 빛 색·세기는 템플릿 장면 빛(`packages/core/src/domain/templates/look.ts`), 구운 조각에는 반구광·환경맵을 작게만 더한다.
- Cycles(Metal 가능하면 GPU), 표본 기본 512(천장 ×4), 시드 고정. 무거운 작업이라 `resource-guard run --profile build`로 한 번에 하나.
- 해상도: 미터당 같게 — 4m 조각(벽·정문) 1024px, 2m 조각·천장·모서리 512px.

## 7. 산출물 검사 (`tools/assets/pipeline/verifyOutput.mjs`)

- 공통: 질감이 KTX2(`KHR_texture_basisu`) · meshopt 압축 · 재질 칸 이름(§4) · 재질 칸 4 이하.
- `core.glb`: 필수 조각(벽 2·4m·문·정문·안·바깥 모서리·천장·바닥) · 굽기 했으면 공통 노출 · 벽·정문 길이(경계 상자 x)가 이름과 ±1mm · 바닥 외 조각에 `TEXCOORD_1` + `occlusionTexture.texCoord = 1` · 삼각형·크기 예산.
- `exterior.glb`: 필수 조각 6개(이름은 `templateGeometry.modules`에서) · 굽기 했으면 외관 공통 노출 · 계단 폭·높이·깊이, 현관 뒷벽·기단, 날개 벽 길이·높이, 판·산울타리 길이 · 가장 넓은 정면 삼각형(외관 문법 `buildExterior`로 조각 수를 센다).
- `fixtures.glb`: 필수 설비 11개 · 삼각형 · 바닥 설비는 바닥 높이 0, 그림자 판을 뺀 넓이가 `footprints` 안(나무는 수관이 넓어 바닥 높이만) · 이젤 받침 높이 = `EASEL_LEDGE_Y_M`.
- 크기: R-3 증가 2MB 이하.

### 9.1 외관 굽기 (조명틀이 실내와 다름)

- **하늘 + 해**: 하늘은 지평선(옅은 청백) → 꼭대기(푸름) 기울기, 해는 **조각 앞(광장 쪽, 세계 −Z)에서 고도 45°**(해에 수직 조도 3.2, 색 따뜻한 흰색, 각 1.5°).
  - 해가 정면이라 현관·박공의 그림자가 현관 안(바닥·뒷벽)에만 떨어지고, 나눠 쓰는 조각(날개 벽·광장 판)에 떨어질 그림자가 생기지 않는다 — 나눠 쓰는 조각은 자리마다 다른 그림자를 가질 수 없다.
  - 산울타리: 해가 조각 **뒤**(광장 쪽 면은 하늘빛만, 윗면은 해) — 뒤 산울타리(광장 쪽 면이 건물을 봄)와 옆 산울타리(해가 비스듬히 스침) 모두와 맞는다.
  - 날개 끝 기둥: 오른쪽·왼쪽 자리 두 번 굽고 화소마다 큰 값(보이는 면은 그 쪽 굽기에서 밝다).
  - 광장 판: 해 + 하늘만(그늘 없음 — 해가 정면이라 건물 그림자는 건물 뒤로 떨어진다).
- **이웃**: 현관·계단은 서로 함께 + 양옆 날개 벽 면 + 땅 + 정문 안 흐린 빛 판, 날개 벽·산울타리는 양옆 8m 같은 조각 사본 + 땅.
- **노출은 외관 조각 전체가 하나**(실내와 따로): 날개 벽 앞면(해 받는 석재 벽, 기단 덮개 바로 위 띠) 평균 밝기가 곡선 뒤 0.62. `manifest.json` `exterior.exposure`.
- **색 있는 구운 빛(RGB)**: 해(따뜻함)와 하늘(푸름)의 색 차이를 그대로 싣는다 — 곡선은 채널마다. 뷰어는 외관 재질의 빛 색을 흰색으로, 세기는 `exterior.viewer.lightMapIntensity`.
- 해상도: 현관 2048 · 계단 1024 · 날개 벽·모서리 512 · 산울타리 256 · 광장 판 16(한결같음).
