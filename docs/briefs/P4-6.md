## 만들 것
1. **부품(모양)** `apps/web/src/ui/patterns/visitor/ReactionSheet.tsx`(+ `.module.css`, `index.ts`에 내보내기)
   - 순수 표시 부품이고 상태는 속성으로 받는다.
   - 스티커 4개(하나 고름, 누르면 작게 튐)
   - 한 줄 메모: 60자는 설정값에서 읽는다. 안내 문구와 글자 수를 보인다.
   - 평가(켰을 때): `사실 정확성`·`전달력` 각 1~3칸
   - `남기기`/`고치기` 단추
   - 위에 작게 "{별명}으로 남겨요 `바꾸기`"
   - 보내는 중·끊김 문구("잠깐 연결이 끊겼어요…")
   - 아래에서 0.3초 동안 올라온다. 동작 줄이기면 바로 나타난다.
   - 규칙(AGENTS §3):
     - 이모지 금지: 스티커는 `<Icon>`이다. 모자라면 보고한다.
     - 기본 `<select>` 금지, `backdrop-filter` 금지, 3D를 덮는 큰 패널 금지(아래 시트 높이는 화면의 절반 안).
     - 터치 영역 44px 이상.
2. **부품(모양)** `apps/web/src/ui/patterns/visitor/PublicReactions.tsx`
   - 캡션 아래 한 줄: 스티커별 수(0은 숨김)와 평가 평균(소수 한 자리)
   - `더 보기` 안에 고른 메모 5개 + `더 보기`
3. **연결** `apps/web/src/app/reactions/`(새 폴더)
   - `ReactionLayer.tsx`: `export const ReactionLayer = (p: { view: ExhibitionView; code: string; artworkId: string; onClose: () => void }) => …`
     - `useServices()`로 api·기기를 받는다.
     - 열 때 `myReactions`로 내 반응을 채운다(전시마다 한 번 받고 기억).
     - `putReaction`으로 보낸다(멱등). 반응 ID는 기기가 만든다.
   - `reactionsEnabled(view): boolean`: 반응 꺼짐이면 `반응 남기기` 자체를 숨기는 판정이다.
   - `PublicReactionsFor`: `(p: { view: ExhibitionView; artworkId: string }) => JSX.Element | null`. 공개가 꺼졌거나 집계가 없으면 null이다.
   - **보내기 줄**(ADR-049): IndexedDB, 반응 ID로 멱등.
     - 끊김·`E_SERVER`·`E_RATE_LIMITED`면 시트를 닫지 않는다. 값은 그대로 두고 줄에 넣는다.
     - `online`·화면 복귀·60초 확인 때 다시 보낸다. 60초는 설정값에서 읽는다.
     - 줄에 남은 것이 있으면 `hasPending()`을 낸다(반응 단추에 작은 점 — Claude가 붙인다).
     - IndexedDB가 막히면 탭 메모리로 둔다.
     - jsdom 시험을 위해 저장소는 주입한다(가짜 저장소).
   - **별명·동의**
     - 별명 방식인데 이 기기가 아직 등록 안 했으면, 처음 반응할 때 PRD 13.2 동의를 받는다. 입장 때 별명을 적었으면 이미 등록돼 있다.
     - P4-1의 `ConsentSheet`·`visitorStore` 등록 로직을 재사용하거나 함께 쓰게 고쳐도 된다. 공개 설정이 '모두에게'를 포함하면 '모두에게' 판을 쓴다.
     - 익명 방식이면 동의 화면 없이 시트 위에 짧은 안내 한 줄만 둔다.
     - `바꾸기`는 별명 바꾸기(`changeNickname`)다.
   - 오류 문구
     - `E_MEMO_BLOCKED`(서버가 `E_VALIDATION {memo:'blocked'}`로 줄 수 있음 — 서버 코드에서 확인)는 칸 아래에 둔다.
     - `E_REACTIONS_OFF`·전시 닫힘이면 시트를 닫고 문구를 보인다.
4. **문구**: 필요한 새 문구는 `packages/core/src/copy/ko.ts`의 `reaction` 묶음에만 더한다(있는 키는 고치지 않음). 학생 문구에는 기술 낱말을 쓰지 않는다.
5. **설정값**: 새 수치가 필요하면 넣지 말고 보고한다(Claude가 `config.ts`에 넣음). 그동안은 파일 맨 위에 이름 붙인 상수로 둔다.
