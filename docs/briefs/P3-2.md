## 목표
PLAN §11(토큰·PIN·남용 막기·머리)의 서버 쪽 보안 모듈을 만든다: 유스케이스 포트 `Security`의 구현, 교사 인증, 속도 제한 칸, 사용자 IP·기기 구분. 라우트 연결은 Claude(P3-3).

## 읽을 것
AGENTS.md(§2·§3), PLAN §9.2 제한 열·§9.3·§11 전체, ADR-024·025·044·048·056, `apps/server/src/ports/index.ts`(`Security`), `apps/server/src/env.ts`(비밀값 `Secret`), `apps/server/src/store/db.ts`·`migrations/0001_init.sql`(`rate_buckets`·`teacher_sessions`·`teacher_devices`), `apps/server/src/http/**`(미들웨어 모양·`AppEnv`), `packages/core/src/config.ts`(`PIN_*`·`CREATE_*`·`REACTION_*`·`CLIENT_IP_HEADER`), `packages/core/src/errors.ts`.

## 고칠 파일(이것만)
- `apps/server/src/security/pin.ts` — `pinHmac(secret, pin)`(HMAC-SHA256 16진), `isWeakPin(pin)`(같은 숫자 반복·오름/내림 연속·흔한 PIN 목록 50개 — 목록은 `security/weakPins.ts`, §11.2).
- `apps/server/src/security/startCode.ts` — 시작 코드 확인(`HMAC(START_CODE_HMAC, code)`를 저장값과 상수 시간 비교 — 저장값을 어디에 둘지는 PLAN·ADR-048을 읽고 정하고 보고), 기기 등록(`teacher_devices`에 기기 해시).
- `apps/server/src/security/tokens.ts` — 받은 토큰 원문 → SHA-256 16진, 상수 시간 비교.
- `apps/server/src/security/rateBuckets.ts` — `rate_buckets` 표 위의 고정 창 칸: `hit(kind, subject, limit, windowSec)` → 허용·잠금·지연. 칸 키 = `{종류}:{HMAC(RATE_KEY_SECRET, 기기 또는 IP)}`(원문 저장 안 함) 또는 `global:{종류}`. PIN 실패 칸 셋(기기 5/10분 → 10분 잠금, IP 30/10분 → 그 IP PIN만 10분 잠금, 전역 100/10분 → 모든 PIN 응답 2초 지연) — 숫자는 `config.ts`. 오래된 칸 정리 함수.
- `apps/server/src/security/client.ts` — 사용자 IP: `CLIENT_IP_HEADER` 머리 하나만(없으면 운영에서 거절, 개발에서는 127.0.0.1), `X-Forwarded-For` 무시, IPv6는 /64로 묶음. 기기 구분: `X-Device-Id`(UUID) → HMAC, 없거나 틀리면 그 IP의 "이름 없는 기기" 칸.
- `apps/server/src/security/index.ts` — `createSecurity(env): Security`(포트 구현)와 위 묶음.
- `apps/server/src/http/middleware/auth.ts` — 교사 인증: `Authorization: Bearer {토큰}` → 해시 → `teacher_sessions` → 전시 ID·세션 종류를 `c` 문맥에(없으면 `E_AUTH`), `last_used_at` 갱신. 전시가 만료·지우는 중이면 `E_NOT_FOUND`.
- 시험: `apps/server/test/security/**`(Vitest, 임시 DB). 쉬운 PIN 판정(가상 예시), HMAC 결정성·비밀값 다르면 다름, 칸(창 경계·잠금 시간·전역 지연, 가짜 시계), IP 머리 규칙(XFF 무시·IPv6 /64·운영에서 머리 없음 거절), 기기 머리 없음·형식 틀림 → 같은 칸, 인증(맞음·없음·지운 세션·만료 전시), 기록에 토큰·IP 원문이 없음.

## 이미 있는 것(겹치지 않게)
- R-5(함께 관람)가 IP 규칙을 먼저 만들었다: `apps/server/src/live/ip.ts`(믿는 머리 하나·IPv6 /64·`::ffff:` IPv4·HMAC 칸 키·고정 창). `security/client.ts`는 이 함수들을 **옮겨 와 한 곳**으로 만들고, `live/ip.ts`는 `security/client.ts`를 다시 내보내기만 하게 바꾼다(`apps/server/src/live/ip.ts`와 그 시험의 가져오기 경로만 고쳐도 됨, 동작은 그대로 — `apps/server/test/live/ip.test.ts`가 그대로 통과해야 함).
