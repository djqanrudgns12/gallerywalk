## 목표
ADR-057(`docs/decisions.md` 맨 끝)의 미술관 외관과 실내 설비를 Blender 스크립트로 만들고 굽는다. 사용자 평가: 지금 실내는 "칙칙하다", 전체가 "저퀄리티", "박물관·미술관 느낌이 적다" → **밝고 고급스러운 고전 미술관**(따뜻한 흰 회반죽·밝은 참나무·연한 석회암/대리석·황동). 저품질 결과는 쓰지 않는다.

## 읽을 것
AGENTS.md(§3·§4·§5), ADR-013·051·057, `tools/assets/spec/modules.md`, `tools/assets/blender/{build.py,geometry.py,textures.py}`, `tools/assets/pipeline/*`, 배치 쪽 계약: `packages/core/src/domain/templates/geometry.ts`(`exterior`·`footprints`·`modules` 이름과 치수 — **이 치수에 정확히 맞출 것**), `packages/core/src/domain/layout/grammar/exterior.ts`(조각을 어디에 어떤 방향으로 놓는지, 기준점 규칙), `packages/core/src/domain/layout/part.ts`(이젤·벤치·화분 자리), `apps/web/src/viewer/scene/TemplateModules.tsx`(조각을 어떻게 읽는지), 지금 캡처 `.local/screens/p2-7/*.png`.

## 만들 것
1. **외관 조각**(같은 core.glb 또는 `exterior.glb` — 나누면 이유를 보고): `mh_ext_portico_12m`(기단·기둥 6개·엔타블러처·**이름판 띠**(y 4.3~5.1, 한가운데 비워 둠 — 글은 뷰어가 그림)·박공·격자 천장·현관 뒷벽(정문 2m×2.8m 열림)), `mh_ext_stairs_12m`(8단, 단 높이 0.15·깊이 0.4, 옆 볼트), `mh_ext_wall_2m`(땅에서 6.2m, 석재 줄눈·기단·코니스, 두께는 뒤로), `mh_ext_wall_end`(날개 끝 모서리), `mh_ext_plaza_2x2`(밝은 화강석 포장), `mh_ext_hedge_2m`(회양목 산울타리 1.1m + 돌 턱). 기준점·방향은 exterior.ts 주석과 geometry.ts 치수 그대로.
2. **정문 조각** `mh_entrance_2m`(홀 뒷벽 가운데, 지금 `mh_wall_door_2m`과 같은 자리 규칙, 더 격 있는 문틀·청동 문짝 열린 모양).
3. **설비 모델**(`fixtures.glb` 등, 지역 +Z = 앞, 기준점 = 바닥 한가운데, `footprints` 치수 안): `easel`(원목 이젤 — 액자 받침 윗면이 y = `EASEL_LEDGE_Y_M`(config.ts), 액자는 뷰어가 받침 위에 그림), `bench`(가죽·참나무 미술관 벤치), `plant`(화분), `lamp`(광장 가로등), `tree`(광장 둘레 나무 — 가볍지만 덩어리 없는 잎 실루엣), 이름판·소개판·사인 판(글 자리 비움).
4. **실내 밝게**: 회반죽·징두리·바닥·몰딩 질감과 색을 밝은 미술관 쪽으로(`textures.py`). 조명틀은 ADR-051 규칙 유지(이음새 시험 통과).
5. **외관 굽기**: 하늘 + 해(외관만 다른 조명틀). 노출은 외관 묶음 하나로, 실내와 따로 `manifest`에 남기고 뷰어가 쓸 세기를 보고.

## 예산(PRD 10장·ADR-057)
외관 전체(가장 넓은 정면 기준) 삼각형 ≤ 40,000, 설비 하나 ≤ 3,000(나무 ≤ 2,500, 잎은 알파 카드 허용), 재질 칸은 조각마다 ≤ 4, 질감 2m당 1장 규칙 유지. glb 합계 증가 ≤ 2MB(KTX2·meshopt 뒤). 실시간 그림자 없음 — 그림자·AO는 구워서.

## 무거운 실행
굽기·glb 빌드는 `resource-guard run --profile build --wait-seconds 1800 -- …`로 한 번에 하나, 백그라운드로 떼지 않는다. 반환 75면 바로 다시 돌리지 말고 `--no-bake`로 형태만 먼저 확인(캡처는 Blender 미리 보기 렌더 1장 정도)하고 보고에 "굽기 미실행"이라고 쓴다.
