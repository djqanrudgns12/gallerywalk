## 고칠 파일(이것만)
- `apps/web/src/ui/tokens.css` — 공통 토큰(간격 4px 단위, 글자 크기 7단계, 모서리 `--r-plate` `--r-sheet`, 그림자 2개, 움직임 시간 = PRD 8.2 표).
- `apps/web/src/ui/themes/modern-history.css`·`apps/web/src/ui/themes/curator.css` — `[data-theme]` 아래 색 변수만(`--plate-bg` `--plate-ink` `--plate-ink-sub` `--plate-edge` `--accent` `--accent-ink` `--scrim` `--danger` `--map-paper` `--map-ink` `--loader-*`). 글자 대비 AA(4.5:1)를 계산해 주석에 값을 적는다.
- `.local/art/p1-7/*.html` — 정적 시안 3장: ① 학생 관람 화면 위 UI(위 줄 + 아래 `‹ 위치 ›` + 줌 캡션 카드)를 3D 캡처 위에 얹은 모습 ② 포스터 화면(기본 포스터 레이아웃) ③ 교사 전시 관리(작품 격자 + 오른쪽 미리 보기 자리). 데스크톱 1440×900·휴대폰 390×844 두 크기 캡처 PNG도 같은 폴더에.
- `.local/art/p1-7/fonts.md` — 세리프 후보 3종(Hahmlet·Noto Serif KR·MaruBuri, 모두 OFL)을 같은 문장("1905 을사늑약과 의병", "하늘고래의 호외")으로 비교한 캡처와 추천 1개와 이유.

## 건드리지 말 것
`packages/**`, `apps/web/src/viewer/**`, `apps/web/dev/**`, `apps/server/**`, `docs/**`, `.env*`, 다른 저장소. 외부 CDN 글꼴·아이콘 주소를 시안에 넣지 않는다(자체 배포 원칙) — 시안 HTML은 로컬 글꼴 파일이나 시스템 글꼴로.

## 지킬 것
파스텔 금지, 이모지 금지, 그라데이션 덩어리·유리 효과(`backdrop-filter`)·네온·순검정 금지, 3D를 덮는 큰 패널 금지, 동시에 열린 창 하나, 터치 44px, 버튼은 아이콘 + 짧은 글자(휴대폰은 아이콘만). 화면 문구는 PLAN §7의 따옴표 문구를 그대로.

## 끝 조건
토큰·테마 파일 + 시안 3장(두 크기 캡처) + 글꼴 비교. 대비 계산값이 주석에 있다. 사용자 1차 의견(U-07)용으로 보여 줄 수 있는 상태.
