## 고칠 파일(이것만)
- `tools/check/*.mjs` — ① 화면·부품 파일(`apps/web/src/screens/**`, `apps/web/src/ui/**`, `apps/web/src/viewer/**`)의 한국어 문자열 리터럴 금지(주석 제외, 문구는 `packages/core/src/copy/ko.ts`만) ② CSS hex 색은 `apps/web/src/ui/tokens.css`·`apps/web/src/ui/themes/*.css` 밖 금지(`apps/web/dev/**`는 예외) ③ 층 위반: `apps/web/src/{ui,viewer,screens}/**` → `apps/web/src/adapters/**` 가져오기 금지, `packages/core/src/domain/**`에서 외부 패키지(zod 타입 제외)·DOM·Node API 금지 ④ 기본 `<select>`·`backdrop-filter`·이모지 금지 ⑤ `packages/core/src/domain/{layout,pages}/**`의 숫자 리터럴(0·1·2·−1 제외, 시험 파일 제외)은 경고 목록으로.
- `tools/check/check.test.mjs` + `tools/check/fixtures/**` — 규칙마다 걸리는 예시·통과 예시(`node --test`).
- 루트 `package.json`의 `scripts` — `check:rules`, `test:checks`를 더하고 `check`에 묶는다(이 두 줄만 고침).

## 건드리지 말 것

## 끝 조건
