## 고칠 파일(이것만)
- `packages/core/src/domain/classify/form.ts` — `classifyForm({kind, w, h, pageCount}) → ArtworkForm`. r = w/h, 경계는 설정 키. PDF·여러 쪽은 첫 쪽 형태를 따르되 결과는 `MULTIPAGE`, 글 → `TEXTCARD`, 소리 → `SOUND`. 경계값 정확히 같을 때 어느 쪽인지 PRD 6.4 표대로(표가 "이상/미만"을 어떻게 말하는지 확인하고 주석에 적기).
- `packages/core/src/domain/classify/textHeavy.ts` — `guessTextHeavy({kind, form, fileName, linePitchPx}) → boolean`(PLAN §5.5: PDF·글 카드·긴 세로·이름 낱말·줄 간격을 찾았으면 켬).
- `packages/core/src/domain/classify/titleFromName.ts` — PLAN §5.2 이름 정리 규칙 그대로. 결과가 비면 **빈 문자열**을 돌려준다(화면이 `copy`의 "제목 없는 작품"을 보임 — 도메인에 한국어 화면 문구를 넣지 않는다). 폴더 이름용 `roomTitleFromFolder`(4자리 연도 + 글자면 앞번호를 남김)와 정렬 키(앞번호)도.
- `packages/core/src/domain/classify/naturalSort.ts` — 자연 정렬 비교 함수(`Intl.Collator('ko', {numeric:true})` + 같으면 원래 문자열로 동률 깸 → 결정적).
- `packages/core/src/domain/classify/folderRules.ts` — `groupUpload(entries: {path, size}[], currentRoom: string|null)` → 전시실 묶음(폴더 이름·정렬 순서·정리한 이름판·그림/문서/글 파일·배경음악 하나·소리 작품들)과 버린 파일 목록. PLAN §5.2 전부(맨 위 폴더 하나면 하위 폴더 = 전시실, 하위 없으면 그 폴더 = 전시실, 파일만이면 지금 전시실, 2단계보다 깊으면 가장 가까운 전시실로 합침, 숨김·시스템 파일 버림, 소리 하나면 배경음악·여럿이면 이름순 첫째가 배경음악). 파일만 올리고 지금 전시실도 없으면 전시실 이름 `null`(화면이 copy "전시실 1"을 씀). 확장자로 종류(그림·PDF·글·소리·영상·그 밖)를 가르는 작은 함수도 여기에(영상은 묶음에 넣되 종류로 표시 — 화면이 "아직 영상은…"을 보임).
