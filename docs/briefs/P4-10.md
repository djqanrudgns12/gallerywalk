## 목표
1. **2D 대체 화면(P4-10, ADR-019, PLAN §6.12)**: 3D로 볼 수 없는 기기에서도 수업 중 빈 화면이 없게 한다.
   - 언제 바뀌는가: 관람 화면 `VisitScreen`(Claude)이 `onFallback2d(reason)`을 한 번 부를 때다.
     - `webgl`: WebGL2를 못 만듦
     - `context`: 60초 안에 컨텍스트 손실이 두 번
     - `fps`: '낮음'에서도 계속 느림
   - 그러면 학생 흐름이 `phase: 'fallback2d'`로 바뀌고 2D 화면을 보인다. 그 전시 동안은 2D로 남는다.
   - 2D 화면은 액자를 하나씩 넘기는 화면이다. 같은 캡션·반응·소리를 쓴다.
2. **P4-11**
   - 동작 줄이기(`prefers-reduced-motion`): 포스터가 사라지는 연출과 시트 올라옴을 바로 바꾼다. 3D 카메라 이동은 Claude 몫이니 보고만 한다.
   - 관람 중 화면 꺼짐 막기: Wake Lock. 들어온 뒤 잡고, 화면을 떠나거나 숨으면 놓고, 돌아오면 다시 잡는다. 지원하지 않으면 조용히 넘어간다.
   - 인앱 브라우저 안내는 P4-1에서 끝났다.

## 만들 것
- `apps/web/src/app/visit2d/Visit2DScreen.tsx`(+ CSS 모듈, 새 폴더): `(p: { view: ExhibitionView; code: string; onHome: () => void; sound?: {on; set} }) => JSX.Element`
  - 위: 전시 이름과 지금 전시실, 그리고 `소리` 단추. 3D가 아니므로 함께 관람 사람 수는 없다.
  - 가운데: 지금 작품 한 점
    - 그림이면 벽용 변형 `<img>`(없으면 썸네일). 글 작품은 종이 카드(HTML 글자, 최소 글자 크기는 PRD 6.8). 소리 작품은 명판과 재생 단추.
    - 소리 재생은 `audioEngine().playArtwork`를 쓰고, 배경음악이 낮아진다.
  - 아래: `ZoomCaption`(제목·작가·캡션). 반응을 켰으면 `반응 남기기` → P4-6 `ReactionLayer`.
  - 넘기기: `‹ ›` 단추·좌우 키·밀기. 순서는 배치의 정지 지점 순서다(`layout.stops`의 작품만).
  - 출구에서는 고마움 인사와 `처음부터 다시 보기`·`처음으로`.
  - 배경음악은 지금 작품이 있는 관으로 `useRoomMusic`.
- 학생 흐름 연결(`StudentExhibition.tsx`·`visitorStore.ts`)
  - `VisitScreen`의 `onFallback2d`를 받아 `phase: 'fallback2d'`로 바꾼다.
  - 3D 관람 화면을 내리고, 그 자리에 `Visit2DScreen`을 띄운다.
  - 이유(`reason`)는 기록하지 않는다. 화면에 따로 알릴 문구가 필요하면 `copy`에 더한다. 학생 문구에는 기술 낱말을 쓰지 않는다. 예: "이 기기에서는 사진으로 둘러봐요".
- Wake Lock: `apps/web/src/app/student/wakeLock.ts`. 훅이고 순수 판정·가짜 `navigator`로 시험한다. 학생 흐름에서 관람 중(3D·2D 모두)에 쓴다.
- 문구: `packages/core/src/copy/ko.ts`에 새 묶음 `view2d`만 더한다. 이미 있는 키는 고치지 않는다.
- 새 수치가 필요하면 넣지 말고 보고한다. 그동안은 이름 붙인 상수로 둔다.
