- `apps/web/src/ui/tokens.css`: `[data-surface="manage"]` 묶음을 더한다. 넣을 토큰:
  - 색: `--manage-ground` #e2dcd2, `--manage-surface` #f3f0ea, `--manage-raised` #fbf9f5, `--manage-viewing` #35312c, `--manage-rule` #d0c8bb, `--manage-rule-soft` #e6e0d6, `--manage-ink`·`-2`·`-3`(#1f1c19·#4b443e·#5e564d), `--manage-frame` #463d35, `--manage-gilt` #8c6d3c, `--manage-warn` #a24f17
  - 그림자: `--elev-1`, `--elev-2`, `--hang`
  - 크기: 액자 높이 `--frame-h-big` 92px·`--frame-h-small` 56px·`--frame-h-tablet` 72px, 대표작 배율 1.2
  - CSS 색 값은 토큰 파일 안에만 둔다(`check:rules`).
- `apps/web/src/ui/patterns/teacher/` 아래 **새 파일만**: 부품마다 `X.tsx` + `X.module.css`, 그리고 `index.ts`에 내보내기 한 줄씩. 시험은 `teacher.test.tsx`에 더하거나 새 시험 파일.
  - `Frame`: 테·흰 매트·그림. 크기(`big|small|tablet`)·`featured`(1.2배·황동 테)·`blurred`·`flag`(확인할 것 점)·`selected`(남색 테두리)·`lifted`(끄는 중 빈자리)
    - 그림 `<img>`는 `draggable={false}`로 두고 CSS에 `-webkit-touch-callout: none`과 `user-select: none`을 넣는다(브라우저 자체 그림 끌기·안드로이드 길게 누르기 메뉴가 끌어 놓기를 가로채지 않게). 이를 단위 시험으로 확인한다.
  - `StatNumber`: 큰 명조 숫자와 이름
  - `StatusPill`: 준비 중/열림/닫힘
  - `Seg`: 두세 칸 고르기. 기본 `<select>` 금지
  - `RoomTiles`: 전시실 번호 타일, 고른 것은 남색
  - `OrderStepper`: 앞뒤 단추, 큰 숫자 `3 / 12`, 눈금 줄
  - `FormChips`: 세로 액자·가로 액자·이젤 그림 칩, `자동` 표시
  - `ToggleTile`: 이름과 스위치
  - `StackBar`: 쌓은 막대와 범례
- 화면 문구는 부품에 박지 말고 props로 받는다(`copy/ko.ts`는 Claude만 고침).
