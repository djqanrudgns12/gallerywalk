# HT-16 · 수업 탭 지도용 전시실별 관람 수 — 맡는 곳: Claude 서브에이전트

작업 폴더: H4 작업 트리(`feat/h4-teacher-v3`, Claude가 만들어 알려 줌)
**모든 출력(보고·진행 문장·문서)은 한국어로 쓴다.**
**시작 조건: Claude가 HT-15를 끝냈다고 알린 뒤에 시작한다.** HT-15가 `LiveStatsSchema`에 칸을 더하고 같은 라우트 파일을 고치기 때문이다.

## 목표
수업 탭 지도(시안 v3.1 `.local/art/teacher-v3/02-desktop-lesson.png`)가 전시실마다 학생 수만큼 점을 그릴 수 있게, 교사용 `/live`가 전시실별 수를 낸다. **개인 위치·토큰·별명은 응답과 기록(1분 기록 포함)에 넣지 않는다.**

## 읽을 것
- `AGENTS.md`, `PRD.md` 18장 G-32(수업 지도 줄), `docs/FIELD_PLAN.md` §5.5 "무엇을 세나"·§5.6 HT-16 줄, ADR-072·ADR-074
- 지금 코드:
  - `GET /api/teacher/exhibitions/:id/live` 처리기(`apps/server/src/http/routes/teacher.ts`)
  - `LiveStats`(`packages/core/src/types/diag.ts`, HT-15 뒤에는 `rooms`·`elsewhere`·`noPose` 칸이 있음)
  - `apps/server/src/live/hub.ts`(멤버 `pose`, 전시별 수 세기)
  - 배치 바닥 다각형 `layout.map.parts[].polygon`과 `partId = {roomId}:{n}`(큰 전시실은 여러 관)

## 고칠 파일(이것만)
- `apps/server/src/live/hub.ts`: 전시별 멤버 위치(x,z) 목록을 내는 **읽기 함수 하나만** 더한다. 위치가 없는 연결(가벼운 화면 등)은 따로 센다. 보내기·받기 흐름은 바꾸지 않는다.
- `apps/server/src/application/liveRooms.ts`(새): 위치 목록 + 배치 → `rooms`(관을 전시실로 합침)·`elsewhere`(홀·광장·복도)·`noPose`를 세는 순수 함수. 시험은 `apps/server/test/application/liveRooms.test.ts`(새).
- `apps/server/src/http/routes/teacher.ts`: `/live` 처리기 한 곳만 고쳐 위 함수를 부른다. 배치가 없으면 `rooms: []`.
- 서버 시험: `apps/server/test/http/`의 교사 시험에 경우를 더한다.

## 건드리지 말 것
`packages/core/**`(스키마는 HT-15가 함), `routes/teacher.ts`의 다른 경로, `application/artworks.ts`, `apps/web/**`, `copy/ko.ts`·`config.ts`(새 숫자가 필요하면 보고), 1분 기록(`ops` 기록)에 전시실별 수를 넣는 것, `.env*`, 운영 자원

## 시험
시험은 원래 Codex 몫이지만 H4에서는 이 작업이 자기 시험을 함께 쓴다(FIELD_PLAN §5.6).

## 끝 조건
- 서버 경로 시험: 두 전시실에 각각 1명·2명, 복도에 1명, 위치 없음 1명 → `rooms` [1, 2], `elsewhere` 1, `noPose` 1. 관 두 개로 나뉜 전시실도 한 수로 합쳐짐. 응답에 좌표·토큰이 없음. 교사 권한이 없으면 지금처럼 막힘.
- 순수 함수 시험(점-다각형 경계 포함).
