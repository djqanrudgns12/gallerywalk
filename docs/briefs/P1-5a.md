## 고칠 파일(이것만)
- 의존성은 Claude가 이미 넣었다(`sharp` 0.35.5, `music-metadata` 12.3.4, `file-type` 22.3.0). `package.json`·`package-lock.json`은 고치지 않는다. 더 필요한 패키지가 있으면 넣지 말고 보고한다.
- `apps/server/src/media/image.ts` — sharp 파이프라인: `.rotate()` → sRGB → 메타데이터 버림 → 파생(`thumb` `wall` `wall-lo` `zoom` `zoom-hi`, 긴 세로·파노라마는 창 부분만 잘라 `thumb`·`wall`, 짧은 변 ≤1440 정규화 후 긴 축 2048px `strip-{i}`). WebP 알파 유지. 결과는 `{ variants: {name, ext, w, h, bytes, path}[] }`.
- `apps/server/src/media/analyze.ts` — `edgeLuma`, 원해상도(짧은 변 2400 이하로만 줄임) 줄 활동 배열 → `linePitchPx`+신뢰도(자기상관), 8px 칸 `lineProfile`(최대 4,096칸). 가장자리 8%는 테두리 때문에 뺀다.
- `apps/server/src/media/heic.ts` — macOS `sips -s format jpeg`(execFile, 시간 제한 `TOOL_TIMEOUT_MS`). 맥이 아니면 `AppError('E_HEIC_UNSUPPORTED')`.
- `apps/server/src/media/audio.ts` — `music-metadata`로 형식·길이. MP3는 ID3v2·ID3v1·APE 태그 제거(표지 그림은 따로 꺼냄). M4A·WAV는 `afconvert`로 AAC(m4a, `AUDIO_AAC_KBPS`). 소리 분석: `afconvert`로 22.05kHz 모노 PCM 임시 → 50ms RMS → `audibleStartMs` `audibleEndMs`(−45dBFS) `loudnessDb`.
- `apps/server/src/media/index.ts` — 위를 묶는 `processImage(inputPath, outDir)`·`processAudio(...)`.
- `apps/server/test/media/*.test.ts` + `apps/server/test/fixtures/make.ts` — **합성 시험 파일을 시험 안에서 만든다**(저장소에 그림을 넣지 않음): GPS EXIF가 든 JPEG, 투명 PNG, 800×20000 긴 세로, 299px·799px, 비율 31, 회전 EXIF(6), ID3+표지가 있는 MP3(짧은 무음 MP3를 만드는 방법이 없으면 바이트로 최소 MP3 프레임을 쓰거나 이 항목은 "미실행"으로 보고), 11분 8kHz 무음 WAV, 앞뒤 무음이 있는 시험음 WAV, 깨진 파일.

## 건드리지 말 것
`packages/core/**`(필요한 것은 보고), `apps/web/**`, `docs/**`, `.env*`, 다른 저장소, 맥미니에서 돌고 있는 서비스.

## 끝 조건
1. 다시 인코딩한 파일에 GPS·위치 메타데이터가 없다(sharp metadata·`music-metadata`로 확인).
2. 투명 PNG 파생이 알파를 유지한다. 회전 EXIF 그림이 바로 선다.
3. 800×20000: 띠 개수 = ⌈20000·(정규화 배율) / 2048⌉, 모든 띠 폭 = 정규화 폭, `thumb`·`wall`이 위쪽 창 비율.
4. 줄 간격 추정: 합성 줄무늬(간격 40px) 그림에서 ±2px, 줄무늬 없는 그림에서 null 또는 낮은 신뢰도.
5. 소리: 11분 WAV는 길이로 거절 가능한 값을 돌려주고, 앞뒤 무음 시험음의 `audibleStartMs`·`audibleEndMs`가 ±60ms, MP3 태그가 사라짐.
6. HEIC: 맥에서 `sips`로 만든 HEIC가 JPEG를 거쳐 같은 파이프라인을 통과(맥이 아니면 건너뜀).
