## 고칠 파일(이것만)
- `apps/web/src/ports/index.ts` — 웹 포트: `ApiClient`(§9.2의 학생 경로 전부 + 교사 경로 중 파일 올리기를 뺀 JSON 경로 전부, 메서드마다 core 스키마의 입력·출력 타입), `DeviceStore`(기기 ID, 최근 전시 목록 최대 `RECENT_EXHIBITIONS_MAX`, 전시별 교사 토큰(링크·PIN 세션)·방문자 토큰, 소리 켬/끔, 동의한 문구 판), `TokenTools`(256비트 토큰 만들기 base64url · SHA-256 16진).
- `apps/web/src/adapters/api/http.ts` — `fetch` 얇은 층: `/api` 기준, JSON 본문, 응답을 `okEnvelope(스키마)`·`ApiErrorSchema`로 검사(어긋나면 `E_SERVER`), 오류 봉투 → `AppError(code, {fields})`, 네트워크 실패 → `E_OFFLINE`, 시간 제한(설정 키가 없으면 보고하고 인자로 받기), 머리 `X-Device-Id`·`Authorization: Bearer`·`If-Match`. 다시 보내기 정책은 호출하는 쪽 몫(여기서는 `retryable`만 실어 보냄).
- `apps/web/src/adapters/api/client.ts` — `ApiClient` 구현(경로·메서드·스키마 짝). 교사 토큰은 `DeviceStore`에서 읽어 원문을 `Authorization`에(서버는 해시만 저장, ADR-025). 방문자 등록·PIN 로그인처럼 **해시를 보내는** 본문은 `TokenTools.sha256Hex`로.
- `apps/web/src/adapters/deviceStore.ts` — `localStorage` 구현(모든 읽기·쓰기를 try/catch — 사생활 모드·꽉 참에서도 앱이 멈추지 않게, 실패하면 메모리로). 저장 값은 zod로 검사해 읽음(바깥 입력). 키 이름은 `gw:` 접두사.
- `apps/web/src/adapters/tokens.ts` — `crypto.getRandomValues` 32바이트 → base64url, `crypto.subtle.digest('SHA-256')` → 소문자 16진.
- 시험: `apps/web/src/adapters/**/*.test.ts`(Vitest jsdom, `fetch`는 `vi.stubGlobal`로 가짜). 봉투 검사(정상·오류·모양 틀림), 오류 코드·`fields` 전달, 오프라인, 머리(`X-Device-Id`·`Authorization`·`If-Match`), 해시 본문, 최근 전시 상한·중복 없음·최신 순, 저장소가 던져도 동작, 토큰 길이·형식, SHA-256 표준 벡터.
