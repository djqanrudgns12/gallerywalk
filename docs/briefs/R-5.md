# R-5 · 함께 관람 서버(웹소켓 중계) — 맡는 곳: Claude 서브에이전트

작업 폴더: /Users/bodyking/Desktop/Architecture/gallerywalk

## 목표
전시마다 웹소켓으로 관람객 위치를 중계한다(ADR-057). 서버는 위치를 **저장하지 않고** 메모리에만 둔다. 끊겨도 혼자 관람은 그대로라 서버는 단순·튼튼해야 한다.

## 읽을 것
AGENTS.md(§2·§3), ADR-057(`docs/decisions.md` 끝), **약속(바꾸지 말 것)**: `packages/core/src/types/live.ts`(메시지 스키마), `packages/core/src/config.ts`의 `LIVE_*`·`CLIENT_IP_HEADER`, `packages/core/src/errors.ts`(`E_LIVE_FULL`·`E_AUTH`·`E_EXHIBITION_CLOSED`·`E_EXHIBITION_DRAFT`·`E_NOT_FOUND`), `packages/core/src/copy/ko.ts`(`live.anonymous`·`live.teacher`), 서버 구조 `apps/server/src/{index.ts,ports/index.ts,application/*.ts,http/**,log.ts,env.ts}`, 저장소 `apps/server/src/store/repos.ts`, 시험 도우미 `apps/server/test/support/{memoryStore.ts,sqliteDeps.ts}`, 웹 토큰 해시 방식 `apps/web/src/adapters/tokens.ts`(토큰 글의 UTF-8 SHA-256 소문자 16진), PLAN §11(남용 막기·IP 규칙). 의존성 `ws@8.22.1`·`@types/ws@8.18.2`는 Claude가 이미 넣었다.

## 만들 것
- `apps/server/src/live/hub.ts` — `createLiveHub({ deps, log, now? })`: 전시별 방(메모리), 연결마다 `sid`(8자 소문자·숫자, 난수 포트 사용), 별명·역할은 **서버 값**(방문자 기록의 별명, 없거나 익명 설정이면 `copy.live.anonymous`의 n = 그 전시 안 순번, 교사 세션은 `copy.live.teacher`). `hello` 검증 → `welcome`(지금 사람들) + 다른 사람에게 `join`. `pose`는 `LIVE_POSE_HZ`보다 잦으면 마지막 것만 남김, 늦은 `seq` 버림. 방마다 `LIVE_BROADCAST_HZ`로 바뀐 사람만 `peers`(자기 자신 제외). 끊기면 `leave`. 사람이 0이면 방과 타이머 정리.
- `apps/server/src/live/attach.ts` — `attachLive(httpServer, hub, opts)`: Node `upgrade` 이벤트에서 경로 `/api/e/{code}/live`(code 6자리 숫자)만 받고 나머지는 소켓을 닫는다. `ws`의 `noServer`, `maxPayload = LIVE_MAX_MESSAGE_BYTES`, `perMessageDeflate: false`. 사용자 IP는 `CLIENT_IP_HEADER` 머리 하나(운영에서 없으면 거절, 개발이면 소켓 주소), IP당 1분 `LIVE_CONNECT_PER_IP_MIN`(메모리 칸, 키는 IP 원문이 아니라 HMAC 또는 해시 — 기록에도 원문 금지). `LIVE_HELLO_TIMEOUT_MS` 안에 `hello`가 없으면 닫기, `LIVE_PING_SEC` 핑/퐁, `LIVE_IDLE_TIMEOUT_SEC` 동안 위치가 없으면 닫기. `close()`로 모두 1001로 닫기(끝내기용).
- 전시·인증 규칙: 입장 코드로 전시를 찾고(없음 `E_NOT_FOUND`), 방문자는 열린 전시만(준비 중 `E_EXHIBITION_DRAFT`, 닫힘 `E_EXHIBITION_CLOSED`), 교사는 그 전시의 교사 세션이면 상태와 상관없이. 토큰이 틀리면 `E_AUTH`. 사람이 상한이면 `E_LIVE_FULL`. 거절은 `{t:'bye', code}`를 보내고 닫기(코드 1008, 꽉 참은 1013). 허브에 `closeExhibition(exhibitionId, code)`(교사가 전시를 닫을 때 Claude가 부름).
- 기록: 연결 수·거절 코드 수만. 토큰·IP·위치·별명은 기록에 넣지 않는다.
- 시험 `apps/server/test/live/**`(Vitest, 실제 http 서버 + `ws` 클라이언트, 임시 포트, 가짜 시계 가능한 곳은 가짜로): 두 사람이 서로 보임(join·peers·leave), 별명은 서버 값(기기가 보낸 다른 값은 무시 — 스키마상 받지도 않음), 위치 횟수 제한·늦은 seq, 형식 틀림 → 닫힘, 너무 큰 메시지 → 닫힘(1009), hello 시간 초과, 꽉 참, 틀린 토큰, 준비 중 전시 방문자 거절·교사 허용, 다른 경로 거절, IP 칸, 기록에 토큰·IP 원문 없음, `close()`.
