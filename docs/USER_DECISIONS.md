## U-01 · 앞단 (CloudFront) — 1안 채택(2026-11-11), 아래는 판단 기록

**확인한 사실 (AWS 공식 문서, 2026-11-11)**
- Free 요금제는 **계정당 3개이고 늘릴 수 없다**. 요금제 하나 = 배포 하나 + 상위 도메인 하나(같은 상위 도메인의 하위 주소는 여럿 가능).
- 지금 세 자리: 쌤유니버스 `E1VKUXOJAO8KBE` · rollingthunder `E3DFFMH3173961` · 글방 `E3TFCRGRU1HG1Q`.
- Free 요금제는 한도(월 100만 요청·100GB)를 넘어도 **추가 요금이 없다**(오래 크게 넘으면 속도만 조정). 캐시·원본 요청 정책은 관리형만 쓸 수 있다.
- 요금제 없는 **종량제** 배포도 같은 계정에 둘 수 있고, 상시 무료 한도(월 1TB·1천만 요청)가 있다. 넘으면 과금되고 상한이 없다.
- **주소는 어느 안이든 `gallery.ssamuniverse.com`으로 쓸 수 있다.** DNS가 Cloudflare에 있어 AWS 계정과 도메인은 서로 묶이지 않는다.

| 안 | 내용 | 비용 | 판단 |
|---|---|---|---|
| **가 (추천)** | 글방 배포에 `gallery.ssamuniverse.com`을 붙이고, 엣지 함수가 주소(Host)를 보고 갤러리 서버로 보냄. 갤러리 캐시 파일은 `/assets/g/` 고유 경로라 글방과 겹치지 않음 | **0원 보장** | 서울 거점. 글방이 아직 운영 전이라 지금 공용으로 설계하는 비용이 가장 작다. 대가: 함수·한도·방화벽 규칙을 글방과 나눠 씀(갤러리 수업 1회 약 5천 요청·0.6GB라 넉넉) |

## U-12 · 학교 안 개인정보 절차

## U-13 · git 저장소·배포 방식

- 지금 `gallerywalk`는 git 저장소가 아니다. P1-1 전에 `git init`과 첫 커밋(문서만)을 해도 되는지.
- 배포 기본값: GitHub 없이 소유자가 만든 `git bundle`을 서비스 계정이 읽음(글방과 같음). 다른 안: GitHub 비공개 저장소 + 읽기 전용 배포 키.

## U-16 · 학교 와이파이 시험 (선택)

## U-17 · 맥미니 설정

- 서비스 계정 `gwsvc`·데몬 등록(sudo), `DATA_DIR`·`MEDIA_DIR` Time Machine 제외, 비밀값 생성 스크립트 실행(시작 코드 값 포함), 전용 터널, Cloudflare 원본 잠금, U-01 결과대로 앞단 설정, 감시 등록. 에이전트가 스크립트와 `docs/runbook.md`를 만들고 사용자가 순서대로 실행한다(약 1시간).

## U-18 · 세리프 글꼴 비교용 파일 내려받기 (2026-11-11 추가)

- P1-7(Antigravity)은 지침대로 외부 글꼴을 받지 않고, 시스템에 있는 세리프로 비교 시안을 만들었다. 실제 세 글꼴로 다시 비교하려면 파일을 받아야 한다(받기는 승인 필요).
- 받을 것: Hahmlet(github.com/hyper-type/hahmlet, OFL 1.1) · Noto Serif KR(github.com/notofonts/noto-cjk, OFL) · MaruBuri(hangeul.naver.com, OFL) — 각 SemiBold·Bold. 원본 3~15MB, 부분집합 woff2는 웨이트당 약 55~110KB.
- 받으면: 비교 시안을 실제 글꼴로 다시 캡처 → U-07 1차 의견 때 함께 고름 → 고른 것만 부분집합으로 자체 배포(외부 주소 없음, PLAN §11.4).

## U-20 · 교실 공용 기기에서 별명 기억 (2026-11-12 추가, P4-1)

- 지금 하는 것:
  - 포스터에서 고른 캐릭터와 마지막 별명을 그 기기에 기억한다.
  - 방문자 토큰도 기기마다 하나다. 그래서 같은 태블릿을 다음 학생이 쓰면 앞 학생의 별명이 미리 채워진다. 반응도 같은 관람객으로 이어진다(기기 1대 = 관람객 1명).
- 기본값(정하지 않으면 그대로): 캐릭터만 기억하고 별명은 미리 채우되 지울 수 있게 둔다(지금 동작).
- 다른 안:
  - (가) 별명을 기억하지 않는다. 매번 빈칸이다.
  - (나) 포스터에 `처음 쓰는 친구예요` 단추를 둔다. 누르면 이 전시의 방문자 토큰을 새로 만든다(공용 기기 수업용).

## U-21 · 화면 글꼴 파일 (2026-11-12 추가)

- 화면 토큰은 Pretendard·Hahmlet을 쓰도록 되어 있다. 하지만 글꼴 파일을 받아 둔 곳이 없어, 지금은 기기 시스템 글꼴로 보인다.
