## 1. 지금 진단 (코드·캡처로 확인한 것)

### 1.1 캡처에서 보이는 것 (CI e2e, 데스크톱 1440×900·휴대폰 390×844)

- **광장**: 회색 타일 한 장이 끝없이 깔린 빈 마당. 장식·식재·빛이 없다. 계단은 넓고 낮아 "단"으로 읽히지 않는다(8단 × 0.15m = 1.2m).
- **입구·회랑**: 폭 4m 어두운 회랑. 남색 판 + 금색 테 매단 판("시험 전시 / 어서 오세요")이 칠판처럼 보인다. 관 이름판은 벽에 아주 작게 붙어 있다. 바닥만 밝은 회색이라 벽·천장과 따로 논다.
- **출구**: 어두운 벽 한가운데 남색 판 하나("출구 / 관람해 주셔서 고마워요").
- **작품 앞**: 액자·빛 웅덩이는 괜찮다. 다만 방이 좁아 카메라가 벽에 붙어 있다.

## 3. 디자인 방향 (아트 디렉션)

### 3.1 한 줄

**"늦은 오후 햇빛의 신고전 미술관 — 밝은 석재 외관, 따뜻한 빛이 고인 어두운 전시실."**
바깥은 밝고 우아하게, 안은 지금의 어두운 톤을 살리되 조금 밝히고 빛의 위계로 고급스러움을 만든다.

**3D로 옮길 때 지킬 것**

1. **M0·M1을 가장 먼저(현장 개선과 나란히)**
   - M0은 그림·설계·결정 페이지라 어떤 파일과도 겹치지 않는다. 시안 승인에 시간이 걸리므로 첫날 보낸다. M3·M4·M5의 모든 에셋이 이 승인에 기댄다.

3. **M1b·M4는 H2 뒤**: 실시간 통로를 현장 개선이 고치는 중이라, 그 결과(v2·배압·다시 그리기 상한) 위에 얹는다. 기다리는 동안 M4의 그림(스티커)·도슨트 3D·대사 카드처럼 통로와 무관한 일은 먼저 한다.
4. **M3 → M5 → M6**은 에셋·조명 굽기라 맥미니 자원(굽기 한 번에 하나)에 묶인다. 굽기를 직렬로 두고 스크립트 작성은 병렬로 한다. 현장 개선의 부하 시험(HS-01)과 같은 때 굽지 않는다.

## 12. 완료 기준 (PRD 15장에 15.10으로 더할 것)

**조작**
- [ ] Space: 도슨트 앞 말걸기, 대문 앞 나가기 창, 그 밖 점프. HUD 단추를 누른 뒤에도 동작한다.
- [ ] 점프가 웅크림·도약·공중 자세·착지로 보이고, 다른 사람 점프도 같은 포물선이다.
- [ ] 사람끼리 세게 부딪히면 둘 다 밀려나고 "부딪히지 않게 조심해 주세요"가 뜬다.
- [ ] 광장 경계에서 부드럽게 밀려나고 "바깥으로는 이동할 수 없어요"가 뜬다.
- [ ] 대문 3m 안에서 `나가기`가 켜지고, `나가기` → 학생 첫 화면, `재접속하기` → 같은 전시 대문 앞.

**공간·디자인**
- [ ] 메인홀 + 두 날개 순환, 방 사이를 문으로 걸어 넘어간다. 모든 방 ≥ 120㎡·천장 ≥ 6m, 방당 작품 ≤ 8, 액자 사이 ≥ 2.0m.
- [ ] 안내판이 3크기 어디서도 잘리거나 압축되지 않고, 소개 정지 지점에서 가려지지 않는다(성질 시험 + 캡처).
- [ ] 계단 16단 + 참, 현관 기둥 8개, 정문·대문이 키 아트와 같은 인상이다(비평 + 사용자 확인).
- [ ] 광장 8방향 어디에도 끊긴 가장자리가 없다.
- [ ] 조형·식물·장식이 규칙(대칭·리듬·시야 금지 구역)을 지킨다.
- [ ] 실내 평균 밝기가 이전보다 15~25% 밝고, 작품이 여전히 가장 밝다.

**함께 관람**
- [ ] 스티커·정해진 말 말풍선이 모든 관람객 머리 위에 보이고, 휴대폰에서 10m 떨어져도 스티커 높이 ≥ 56px.
- [ ] 30명이 동시에 말풍선을 보내도 그리기 +2 이하.
- [ ] 교사가 끄면 보내기 단추가 사라지고 서버가 거부한다. 자유 글은 교사가 켤 때만.
- [ ] 도슨트 3명이 서로 다른 인물로 자리에 서서 바라보고 손짓하고, 이따금 예절 말풍선을 띄운다. `말걸기`는 섞은 순서로 한 줄씩.

**성능**
- [ ] 그리기 ≤ 120(터치)/160, 삼각형 ≤ 30만, 광장 첫 화면 ≤ 6MB, 혼자 멈추면 다시 그리기 0.
