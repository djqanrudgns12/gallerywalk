## 0. 한 줄 판정

목적·화면·연출 기준은 구체적이고 좋다. 다만 그대로 구현하면 첫 수업에서 문제가 될 것이 다섯 가지 있다. (1) **한국 회선과 무료 플랫폼 가정**(Cloudflare 무료 경로·CloudFront 무료 자리 없음), (2) **웹툰·A4 읽기 규칙의 산술 오류**, (3) **iPad GPU 메모리 산술 초과**, (4) **iOS 소리 볼륨 제어 불가**, (5) **브라우저 처리 전제(Safari WebP 인코딩·HEIC)**. 다섯 모두 `[추천]` 층에서 풀려 PRD의 `[고정]` 요구는 그대로 지킨다. `[고정]` 해석이 필요했던 두 개(휴대폰 세로 A4, 투어와 노래 길이)는 2026-11-11 사용자 지시로 닫혔다(ADR-047·046).

## 5. 독립 검토(Antigravity)와의 대조

- 18건 가운데 16건은 같은 결론이거나 반영했다(ADR-043 목록).
- 반영하지 않은 4건과 이유는 ADR-043 "반영하지 않은 것"(G-09·G-17 `[고정]`과 부딪침, 토큰 쿠키 대신 Bearer, 화각 고정 대신 절충).
- Antigravity가 사용자 결정으로 올린 6건 중 PIN·원본 보관·마스코트는 PRD `[추천]` 범위라 에이전트가 정했고(ADR-024·004·041), 투어 노래 길이는 사용자가 정했고(ADR-046), 별점 노출은 G-09 `[고정]` 때문에 열기 시트 요약으로 바꿔 반영했다.

## 6. 계획 독립 검토 (Codex, 2026-11-11)

- PLAN 초안을 Codex(deep, 읽기만)가 PRD·ADR과 대조해 23건(높음 15·보통 7·낮음 1)을 냈다. 모두 PLAN 원문과 공식 문서로 확인했고 전부 반영했다(ADR-045 목록).
- 새로 확인된 사실: Cache API는 HTTP 캐시 머리로 만료·삭제되지 않음 / `ImageBitmap`은 three `Texture.flipY`·`premultiplyAlpha`가 무시됨 / gltf-transform `prune`은 참조되지 않는 자원을 지움 / CloudFront는 `X-Forwarded-For`에 시청자 IP를 덧붙이므로 첫 값을 믿으면 안 됨 / busboy는 `limit`·`truncated`로 한도 초과를 알림.
- "문제없다고 본 핵심 결정"(Codex): 서버 sharp 처리·띠 저장·WebP 알파, SQLite STRICT·부분 유니크 색인, R3F demand·`initTexture`·같은 UV 모듈 인스턴싱, HTML 줌·2D 대체·GPU 예산·실기기 선행 관문, 자체 배포 CSP·Bearer 토큰 해시·CSV 수식 방어.

## 7. 쌤유니버스 정찰 요약 (PRD 0.2-2)

- 쌤유니버스: 맥미니 자체 호스팅(Colima VM 안 Docker compose, Caddy → NestJS, Keycloak, Postgres 18 컨테이너, 파일은 VM 볼륨), CloudFront 서울 Free → Cloudflare WAF → cloudflared. 3D·오디오·QR·업로드·욕설 필터 코드는 없다. 가져올 것은 토큰 방식 디자인 규칙(hex 금지·아이콘 생성기)과 운영 스크립트 틀.
- 서브 URL로 붙이면: CloudFront 동작 5개를 이미 다 써서 갤러리 자산이 캐시 없이 맥미니까지 가고, 세션 쿠키·CSP·배포·백업이 묶인다 → 별도 하위 도메인(ADR-002).
- 판 관례: npm workspaces, Node 24, Vite 8, React 19.3, react-router-dom 7.18, TypeScript 5.9.3, zod 4, Vitest 5, Playwright, `save-exact`(ADR-030).
- 포트: 쌤유니버스 4380·4390 외 스크립트용 4470 등, 글방 4460~4462·20242, rollingthunder 3000·8000·20241 → 갤러리 4520~4522·20243(ADR-040).
